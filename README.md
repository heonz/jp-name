# 일본 이름 작명소

내 이름 한자를 일본식(음독·훈독)으로 읽어 일본 이름 3개를 추천하는 밈 사이트.
Cloudflare Pages(정적 페이지) + Pages Functions(API 키를 숨기는 서버)로 돌아가요. **서버는 무료 플랜으로 충분해요.** 돈이 드는 건 Claude API 사용료와 (원하면) 도메인뿐이에요.

```
public/
  index.html      메인 페이지 (사전 모드 내장 → AI가 안 돼도 동작)
  about.html      음독·훈독 설명 (광고 심사용 콘텐츠 겸용)
  privacy.html    개인정보처리방침 (대괄호 부분 채우기)
  og.png          카톡·SNS 링크 미리보기 이미지
functions/api/
  name.js         POST /api/name → Claude 호출, 캐시, 속도 제한, 일일 한도
wrangler.toml     배포 설정
```

## 배포 (30분 정도)

1. **Anthropic API 키 만들기**
   console.anthropic.com → API Keys에서 키 발급.
   **Billing에서 월 사용 한도(spend limit)를 꼭 걸어 두세요.** 트래픽이 터져도 이 금액 이상은 안 나가요.

2. **Cloudflare 계정 만들기** (무료)
   ```bash
   npm i -g wrangler
   wrangler login
   ```

3. **배포**
   ```bash
   wrangler pages deploy
   wrangler pages secret put ANTHROPIC_API_KEY
   ```
   (GitHub에 올리고 Cloudflare 대시보드에서 Pages 프로젝트로 연결해도 돼요. 그 경우 시크릿 `ANTHROPIC_API_KEY`는 대시보드 Settings에서 추가.)

4. **도메인 연결**
   짧고 기억하기 쉬운 도메인 하나 사서 Pages 프로젝트 → Custom domains에 연결.
   광고 심사는 `*.pages.dev` 주소로는 받기 어려우니 도메인은 거의 필수예요.

5. **확인**
   사이트에서 이름을 지어보고 오른쪽 위에 `AI 작명` 태그가 뜨면 성공. `사전 규칙 작명`이 뜨면 API 키 설정을 다시 확인.

## 무료 플랜으로 버티는 범위

- 페이지·이미지 같은 정적 파일: 무료, 무제한.
- 이름 짓기 API(`/api/name`): 무료 플랜은 하루 10만 요청까지. 넘으면 그날은 화면이 사전 모드로 넘어가요(사이트는 계속 열림).
- 결과 캐시: 무료 플랜에서는 Cloudflare 캐시(Cache API)를 써요. 쓰기 제한이 없고 돈도 안 들어요. 데이터센터별로 따로 쌓이지만 한국 사용자는 대부분 같은 곳으로 붙어서 효과는 충분해요.
- 무료 플랜에는 IP 속도 제한·하루 한도가 없어요. **그래서 Anthropic 콘솔의 월 사용 한도가 유일한 안전장치예요. 꼭 걸어 두세요.**
- 하루 10만 요청을 넘길 만큼 터지면 그때 Workers 유료 플랜($5/월)으로 올리고 `wrangler.toml`의 KV 주석을 풀면 돼요.

## 설정값 (wrangler.toml `[vars]`)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `MODEL` | `claude-haiku-5-5` | 쓸 모델. 품질을 더 올리고 싶으면 `claude-sonnet-5-5` (비용 몇 배) |
| `DAILY_CALL_LIMIT` | `30000` | (KV 연결 시) 하루 AI 호출 상한. 넘으면 자동으로 사전 모드 |
| `IP_LIMIT_PER_10MIN` | `20` | (KV 연결 시) IP 하나당 10분 요청 수 |

## 실패 원인 보기

AI 작명이 실패하면 Cloudflare 대시보드 > 내 Worker > **Logs**에 `[name]`으로 시작하는 줄이 남아요(무엇이 왜 실패했는지). `wrangler.toml`의 `[observability]`가 이 기능을 켜요.

## 비용 감

- 이름 한 번 지을 때 입력 약 1,300토큰 + 출력 약 400토큰.
- Haiku 5.5 기준(입력 100만 토큰당 $0.10, 출력 $0.50 — 공식 가격표에서 다시 확인 필요) 한 번에 약 $0.0003~0.0004.
  **AI 호출 10만 번에 대략 $30~40.**
- 같은 한자 조합은 30일 캐시돼서 두 번째부터는 무료예요. 金·李·朴 + 흔한 이름 글자가 많아서 실제 비용은 이보다 꽤 낮을 거예요.

## 광고 붙이기

**지금 바로 신청부터 하세요.** 승인까지 걸리는 시간이 밈 수명(1~2주)보다 길 수 있어요.

- **카카오 애드핏**: 승인·초대받은 매체만 가입할 수 있어서 먼저 제휴 문의를 넣어야 해요. 가입 후 광고 스크립트를 설치하면 심사는 보통 영업일 1~2일.
  지급은 늦어요: 한 달 적립금을 다음 달 21일에 요청하면 그다음 달에 입금.
- **Google AdSense**: 승인 기간이 들쭉날쭉하고, 페이지가 하나뿐인 도구형 사이트는 "가치 없는 콘텐츠"로 거절당하는 경우가 많아요. `about.html`처럼 읽을거리 페이지를 몇 개 더 두면 유리해요.
- **쿠팡 파트너스**(보조): 승인 없이 바로 링크를 걸 수 있어요. 단, "쿠팡 파트너스 활동의 일환으로 수수료를 받을 수 있음" 문구를 반드시 표시해야 해요. 일본 여행 소품, 일본어 교재 같은 연결이 자연스러워요.

### 광고 자리

광고 자리는 두 곳이에요. 주소 끝에 `?adpreview`를 붙여 열면(예: `https://내주소/?adpreview`) 광고가 들어갈 자리와 크기가 점선 상자로 보여요.

| 자리 | 위치 | 휴대폰 | PC |
|---|---|---|---|
| A (`mid`) | 추천 이름 3개와 여행 카드 아래 | 300×250 | 728×90 |
| B (`bottom`) | 페이지 맨 아래 | 320×100 | 728×90 |

광고 승인을 받으면 `public/index.html`에서 `const ADS=` 부분만 채우면 돼요.

- **카카오 애드핏**: `provider:'adfit'`으로 바꾸고, 애드핏에서 위 크기대로 광고 단위를 만든 뒤 `DAN-...` 코드를 `adfitPC`, `adfitMobile`에 넣어요. (자리마다 PC용·휴대폰용 2개, 총 4개)
- **구글 애드센스**: 심사 중에는 `provider:'adsense'`, `adsenseClient:'ca-pub-...'`만 넣어 두면 돼요. 애드센스가 준 심사용 코드는 `<head>` 안 주석 자리에도 붙여 두세요. 승인 후 광고 단위를 만들고 숫자 ID를 `adsenseSlot`에 넣어요. `public/ads.txt`의 줄도 내 pub 번호로 바꿔서 주석(#)을 풀어요.

광고를 달면 `privacy.html`의 광고 서비스 이름과 연락처를 꼭 채워 넣으세요.

## 여행 제휴 링크 (사업자등록 없이 가능)

결과 아래에 "OO 씨에게 어울리는 여행지는 교토" 카드가 떠요. 여기에 여행 제휴 링크를 넣으면, 방문자가 그 링크로 예약할 때 수수료를 받아요.

- **마이리얼트립 파트너스**: 한국어, 가입 쉬움. 투어·입장권·숙소.
- **클룩 어필리에이트**: 일본 투어·JR패스·USJ 입장권이 강함.
- **아고다 파트너스**: 일본 숙소.

넣는 곳: `public/index.html`의 `const TRAVEL=` 항목.
- `tour`, `esim`, `hotel` 세 칸에 제휴 링크를 넣으면 카드가 켜져요. 하나만 넣어도 돼요.
- 도시별 페이지 링크를 따로 만들었으면 `cities` 안에 넣어요. 예: `osaka:{tour:'https://...'}`
- 링크가 하나도 없으면 카드는 숨겨져요. `?adpreview`로 열면 빈 카드 모양을 미리 볼 수 있어요.
- 카드 아래 "제휴 링크예요…" 안내 문구는 법적으로 필요한 표시라 지우지 마세요.

## 같은 이름, 다른 결과

- 같은 한자 조합(동명이인)이 들어오면 처음 4번까지는 매번 새로 지어서 서로 다른 결과를 모아요. 4개가 모이면 그중 하나를 무작위로 보여줘서 AI 비용이 더 늘지 않아요. 개수는 `functions/api/name.js`의 `VARIANTS`로 바꿀 수 있어요.
- "다른 이름 3개 더 보기" 버튼은 저장된 결과를 쓰지 않고 지금 보이는 이름을 피해서 새로 지어요.
- 공유 링크에는 결과 자체가 담겨요(`r=`). 링크를 받은 사람은 AI를 다시 부르지 않고 똑같은 결과를 봐요.

## 밈으로 돌게 만드는 장치 (이미 들어 있음)

- **공유 링크**: 이름을 지으면 주소에 결과가 담겨요. 이 링크를 받은 친구는 같은 결과를 바로 보고 → 자기 이름도 넣게 돼요. 이 경로는 AI 비용이 들지 않아요.
- **공유 카드 이미지**: 인스타 스토리 비율(1080×1350). 휴대폰에서는 `공유하기` 버튼이 카톡·인스타 공유창을 바로 열어요.
- **링크 미리보기**: `og.png`가 카톡·트위터 미리보기로 떠요.
- **AI가 안 돼도 동작**: 한도를 넘거나 API가 막히면 내장 사전 모드로 자동 전환돼서 사이트가 죽지 않아요.
